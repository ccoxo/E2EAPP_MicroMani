# 控制恢复与审查整改（2026-09-14）

本次修改针对附件审查中经当前源码确认的问题。未启动硬件、未提交或发布代码。

## 控制权与恢复

- 一个后端同时只接受一个控制浏览器。其他控制连接以 WS 1008 拒绝，前端不自动重试抢占。
- 观察页面使用 `?mode=observe`；WS 同样带此参数。观察页接收遥测，不参与租约，也不能发送受保护运动命令。页面内切换路由后重连仍保留观察身份。
- HTTP 控制请求携带 `X-Control-Session`，值来自该浏览器自己的挑战会话。缺少或不匹配会话的请求不能借用其他页面的租约。
- 旧会话 trip 后退出控制集合；旧应答、旧发送错误和旧断开不会影响新会话。每次新续租仍消耗新的主线程挑战应答。
- 恢复顺序为：新连接 → 新挑战 → HAL 确认租约 → 停止任务结束 → 操作者安全 ACK → 操作者重新使能。续租不清除急停、不恢复旧队列。
- 页面异常提供显式重新连接/重试入口。未捕获异常继续采用保守撤权策略。
- 浏览器退出的句柄释放/停栈请求绑定最后控制会话，观察页或旧页面不能释放新控制者的资源。

入口：[watchdog](../backend/services/control_watchdog.py)、[安全门槛](../backend/core/motion_safety.py)、[前端连接](../frontend/src/stores/telemetry.ts)。

## 执行准入与操作协调

- 共享 MotionSafetyGate 在检查停止代际和急停时同步检查浏览器及 HAL 租约；应用装配时注入，不以 Test HAL 模式绕过。
- 服务操作按左右运动资源互斥，同一任务的嵌套调用可重入，冲突的新操作直接拒绝。覆盖使能、手动、回原点、原点修改、策略派发、遥操作启动和录制启动/重置入口。
- 普通运动的等待后复查仍保留；策略在最终位置验证后再次检查自动停止代际。停止、断使能及关闭力反馈继续可用。
- 涉及运动、力、遥操作、夹爪、自动控制或 HAL 的配置更新要求租约、静止反馈和资源互斥；普通显示配置不因缺租约拒绝。快照应用遵循相同规则。
- 原点捕捉、恢复和清除要求新鲜静止反馈。回工作原点在 HAL 返回后继续确认六轴停止且距目标不超过 1 pulse；确认窗 2 秒，反馈最大年龄 500ms。失败不显示到位成功。
- 当前硬件契约维持每侧六轴。前端取消右侧 Yaw 例外和聚合使能兜底；未引入未经设备核实的“安装轴”配置。
- PreCheck 人工勾选须已有回原点确认；录制启动和跳过复位还会在服务端重新核对工作原点，避免依赖历史勾选。

入口：[命令服务](../backend/services/command_service.py)、[策略服务](../backend/services/policy_service.py)、[API 装配](../backend/app.py)。

## 超时与执行结果

- 前端命令请求具有 AbortController 和有界等待：普通命令 10 秒，回原点命令 80 秒。终止客户端等待不代表后端动作已取消。
- 受保护命令超时撤销前端控制租约，清除后续使能意图，显示“执行结果未知”。回原点入口在共享 API 边界互斥。
- 策略区分已进入 HAL 后被停止打断、等待应答和结果未知，不再用 `dispatched: false` 暗示已下发动作从未发生。
- 保留 DDS 原生阻塞隔离和急停 lane 容量 1。不强制释放仍被原生调用占用的 slot，不为重试增加无界线程。
- watchdog 只对已返回的停止失败进行有限重试；DDS 已隔离时不重试。关停对停止和发送任务的等待有界。
- HAL Guardian 的 2500ms 是租约期限，不是机械停止完成时间。原生传输已隔离或 Guardian 永久故障仍需要受控重启，浏览器重连不能解除这些故障。
- 保留保守的租约确认截止时间，没有把 ACK 往返耗时补回租约。

## 数值与录制

- 手动请求模型和服务层拒绝非有限/负步长；策略拒绝非有限步长、非正速度、非法方向及非法上限。
- 位置、原点和软限位必须有限，限位须有序；策略派发复用最新位置边界及轴使能校验。
- Test HAL 模拟租约期限、所有者、序号重放拒绝、急停及显式 ACK，不再对运动恒成功。
- 急停同步关闭新帧入口，异步停止录制来源并排空已接受的帧；未保存片段保留待人工保存或丢弃，不直接调用清空 buffer 的 finish 流程。
- 录制清理异常不能阻断硬件急停。前端保留“中断”状态和保存入口；恢复控制不自动重启录制。
- 顶栏频率使用遥测值，移除固定“检测通过”；轴数组订阅使用浅比较。
