# Card 0 Yaw 全链路运动权限恢复设计

日期：2026-08-04

## 目标

恢复操作者视角左臂 Yaw 的全部运动权限。当前遥操作采用交叉路由，操作者左臂对应硬件右臂 Card 0，因此本次解除 Card 0 Yaw 的永久软件禁用。

完成后，Card 0 Yaw 可通过既有的轴使能、硬件回零、回工作原点、手动点动和遥操作路径运动。现有急停、安全锁存、伺服使能检查、单步上限和 Yaw 工作软限位继续生效。

## 当前问题

Card 0 Yaw 在多个层级被独立阻断：

- 配置归一化强制把对应遥操作轴掩码设为禁用。
- 后端回零和回工作原点使用固定禁用轴掩码。
- 后端拒绝 Card 0 Yaw 手动点动。
- HAL 命令分发再次拒绝 Card 0 Yaw 手动点动。
- LTDMC 驱动把 Card 0 Yaw 视为永久禁用，并在使能、回零、回工作原点、手动点动、遥操作和状态判断中跳过或拒绝该轴。
- 前端按卡号禁用手动控制并显示 `Yaw disabled`。

只解除其中一层会造成不同入口权限不一致，因此需要全链路同步恢复。

## 设计

### 配置与迁移

删除 Card 0 Yaw 的强制禁用规则。现有配置中由旧规则留下的对应 Yaw 轴禁用值恢复为启用，默认配置也保持启用。其他轴掩码不变，不新增权限开关或配置项。

### 后端控制

- 回零、回工作原点和使能请求对 Card 0 使用完整六轴掩码。
- 原点有效性和目标软限位校验重新包含 Card 0 Yaw。
- 删除手动点动中的 Card 0 Yaw 永久策略拒绝。
- 保留现有手动步长、速度、伺服状态、工作原点及软限位校验。

### HAL 与驱动

- 删除 HAL 命令分发中的 Card 0 Yaw 特判。
- 删除 LTDMC 驱动中的 Card 0 Yaw 永久禁用概念及所有依赖分支。
- Card 0 Yaw 与其他旋转轴沿用相同的使能、回零、绝对运动、相对点动、遥操作目标更新和停止逻辑。
- 不改变 Card/物理轴映射、脉冲当量、运动 profile 或急停逻辑。

### 前端

- 取消 Card 0 Yaw 手动控制禁用。
- 删除对应的阻断提示。
- 将卡片中的 `Yaw disabled` 改为现有 Yaw 工作角度范围说明。

## 安全边界

本次恢复运动权限，不扩大运动范围。以下保护保持不变：

- Yaw 工作软限位默认维持 `-7°～+7°`。
- HAL 单次旋转点动最大值维持现状。
- 未使能伺服时禁止运动。
- 急停或安全锁存生效时禁止运动。
- 回工作原点前继续校验原点有效性及目标软限位。

## 测试与验收

遵循测试先行：先把旧的“Card 0 Yaw 必须禁用”断言改为期望恢复权限，并确认测试因现有实现而失败；然后实施最小修改。

验收条件：

1. 配置加载后，Card 0 对应侧的 Yaw 遥操作轴默认启用。
2. 后端允许 Card 0 Yaw 进入手动点动流程，并仍执行软限位及伺服检查。
3. 使能、硬件回零、回工作原点请求包含 Card 0 Yaw。
4. HAL 分发与 LTDMC 驱动不再永久拒绝或跳过 Card 0 Yaw。
5. 遥操作目标更新可处理 Card 0 Yaw。
6. 前端 Card 0 Yaw 控件可用，不再显示永久禁用文案。
7. 相关后端、前端测试通过，HAL 构建成功。

## 非目标

- 不修改左右臂交叉路由。
- 不调整 Yaw 软限位数值。
- 不修改物理轴映射、方向、脉冲当量或速度参数。
- 不新增依赖或配置开关。
- 不改动与本需求无关的现有工作区变更。
