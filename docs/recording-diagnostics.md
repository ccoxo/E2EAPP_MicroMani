# 录制卡顿诊断

正常录制默认关闭逐帧诊断及线程栈采样。编码丢帧检测和禁止保存缺帧 episode 的保护始终生效。

需要排查时，在启动后端的 PowerShell 中设置环境变量，再从同一终端启动应用：

```powershell
$env:APPSTATION_RECORDING_DIAGNOSTICS = '1'
```

每个采集会话启动后最多记录 180 秒，文件位于 `backend/runtime/record-trace-*.jsonl`，独立于训练数据。记录采样时间、选帧时间戳、组帧和写入耗时、编码队列、超过 10 毫秒的垃圾回收停顿，以及每约 100 毫秒一次的 Python 线程栈；不记录图像和局部变量。

诊断结束后，将变量设为 `0` 并重启后端，恢复正常录制模式。设置环境变量不会改变已经运行的后端。既有诊断文件保留，可用于科研对照。
