## 全局策略

| 维度 | 调整前 | 调整后 |
| --- | --- | --- |
| 背景 | 多套浅灰蓝并用 | 统一 #EEF1F5 |
| 状态 | 卡片左色条 | 点 + 短标签，异常才染色 |
| 顶栏 | 48px 塞满 | 薄仪表条，状态收敛 |
| 底栏 | Log + Status 双条 | 单状态条 + Log 可折叠 |
| 急停 | 悬浮红块 | 右下急停坞 |
| 数据 | 混用字体 | 等宽 tabular |
| 图表 | 六色无语义 | 操作蓝为主，状态色点缀 |

## 分页差异

### 主页
- 前：左色条四格 + 双臂条纹噪音
- 后：Safety 横幅 → 状态点卡片 → 设备 chip → 数值单元格 + 力觉汇总

### 录制
- 前：相机标题重、监看挤成一片
- 后：相机作主角（全局加宽）；位姿 / 轴计量 / 力觉三栏；危险度置顶侧栏

### 数据集
- 前：空态大片留白，主次按钮不清
- 后：数据集列表 + 摘要指标条 + 三路回放 + 轨迹/力觉曲线

### 模型
- 前：三卡同权，延迟条语义弱
- 后：卡片强调延迟与就绪态；主操作强调；精度分段统一

### 微调
- 前：表头塞输入框；空表 No data
- 后：创建任务独立表单分区；任务表带状态点与操作

### 自动
- 前：浅色相机占位、控制区层级平
- 后：深色相机腔体；队列图 + 指标盒；算法/模式分段控件

### 设置
- 前：焦点条信息密，字段平铺
- 后：四格焦点卡 + Tab 分区；安全阈值分组，急停字段轻染
